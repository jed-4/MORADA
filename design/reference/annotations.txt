# Designer annotations (what changed and why), copied from the Figma annotation frames.
# Note: the 'Projects v3' notes describe v3; the approved Projects v4 swaps the left colour bar for the small colour square.
# Workspace v4 and Projects v4 have no annotation of their own; the v3 notes still apply. Schedule notes in "Project tasks & schedule v2" were superseded by the Schedule v3 notes (and List v4 = v2 list body + v3 header/tabs).

=== 21:538 Annotation — Workspace v3
Workspace v3 — changes vs v2
1
Projects capped at 5 rows
Pinned projects first (tiny pin icon), then the most recently active. A quiet “+35 more ›” row in #9B968F opens the Projects tab. The header still shows the full count, 40. Works for Jed (40) and for team members (~6).
2
Every section collapses
Tap the title to toggle. A tiny caret after the title shows the state: down = open, right = collapsed. Collapsed = header row only, with the count. The full-scroll frame shows Timesheets collapsed.
3
No more text links
“See all” and “Open calendar” are gone. One small muted chevron (#9B968F, 16px) at the far right of each header opens the full list: “Projects 40 ›”.
4
Header pattern
Left: grey line icon, 15pt semibold title, caret, muted count. Right: open-list chevron. Same on every card.
5
Kept from v2
Compact quick capture chips, white section cards on #FBFAF8, Today merging tasks and schedule, condensed activity.

=== 26:1028 Annotation — Projects v3
Projects v3 — minimalist pass
1
Quieter cards
Address (bold) + short price ($486k, $1.19m) on top, client below. No % text. Only Construction cards show a progress line; elsewhere the left colour bar carries the colour.
2
A vs B
v3A bordered: white cards with a 1px #EBE8E3 border. v3B borderless: white cards on #FBFAF8, separated by spacing only (no shadow).
3
Search on demand
Search bar and chips removed. Header = Projects + muted count, with search and + icons. Tapping search shows a field plus All / Mine / Construction / Post-con chips (see “search open”).
4
Calmer groups and type
Group headers lose their icons: title, caret, muted count, muted ›. Post-construction is collapsed by default. Only the address is bold; everything else is regular, and all secondary text is #9B968F.
5
Dummy data
Clients, contract prices, progress and group counts are placeholders.

=== 33:1396 Annotation — Project detail v3
Project detail v3 — what changed
1
Sections one tap away
A row of quiet tiles sits right under the header: grey line icon, label, muted count. White with a 1px #EBE8E3 border, no pastel colours. It replaces the original tile row, in the new style.
2
v3A: scrolling row
Nine 76×64 tiles: Tasks, Schedule, Variations, Selections, Scope, Documents, Diary, Checklists, Defects. The cut-off tile at the right edge hints that it scrolls. Only one row high, so the overview still shows above the fold.
3
v3B: 4×2 grid
Seven sections plus a More tile (Checklists, Defects) are visible at once with no scrolling, at the cost of about 70px more height.
4
Capture moved to a + button
Photo / Diary / Defect / Variation now open from one floating + button above the tab bar, so the top of the screen holds a single row of controls instead of two. Tapping + would open the four chips as a small sheet.
5
Everything else as v2
Same header, overview and collapsible section cards. Defects is added as a collapsed card. All data are placeholders.

=== 35:492 Annotation — Messages v3
Messages v3 — what changed
1
Pinned on top, then one inbox
Only Pinned keeps a small group card with the minimal header. Everything else is one list sorted by latest message, newest first, so whatever was updated last rises to the top.
2
Mixed thread types, one list
Project threads, channels and DMs sit together. The marker shows the type: project-colour square, muted #, or grey initials circle.
3
Quiet label, no grouping
A muted "Recent" label sits above the list card. It has no caret or count, because the list is never collapsed or split up.
4
Unread in purple only
An unread thread gets a semibold name, a purple time and a purple count badge. Times run 2m, 14m, 1h, 3h, Yesterday, Thu, Mon, 12 Nov, 27 Oct, 17 Jul.
5
Dummy data
Names, previews, times and counts are placeholders.

=== 40:658 Annotation — Project tasks & schedule v2
Tasks & Schedule v2 — what changed
1
Tasks: groups without the noise
Header is ‹ Tasks with the project square and name, plus quiet show-completed and view icons. No tinted bar. Groups are sentence-case headers with a caret and muted count, and tasks sit in one bordered card each (round checkbox, title, muted due · initials). Empty groups fold into one "Show empty groups" line.
2
Schedule list: calm status
A quiet List / Gantt / Calendar switch. Items are grouped by start date in bordered cards: title, muted dates · trade, and a small status dot (green Done, purple In progress, grey Upcoming) instead of loud pills. Done titles are muted, and older finished items collapse into "8 earlier items done".
3
Gantt: just the bars
A narrower item column in sentence case, no alternating fills, faint gridlines, today as a faint purple column with a thin line. Bars use the Calendar v4 tint + 3px strip in three calm trade colours (slate, blue, teal). Items beyond the range show their date at the edge.
4
Calendar: same as Calendar v4
One row with November 2026 and ‹ ›, Month / Week as quiet text, events as tint + strip blocks, purple now-line. The second filled control is gone.
5
One + everywhere
The floating purple + from Project detail v3A sits on all four screens. All data are placeholders.

=== 46:534 Annotation — Defects v2
Defects v2 — what changed
1
List: one header, quiet filters
‹ Defects with the project square and name muted, search and filter icons. Status is one scrollable row of small chips with counts (All, Open, Sent to trade, Accepted, Rejected, Closed). Job stage, Mine and Overdue move behind the filter icon.
2
Grouped rows
Defects are grouped by location under collapsible headers, as rows in one bordered card: a 48px photo, muted D-number + full-width title, then a meta line starting with a status dot + word (amber Open, blue Sent to trade, green Accepted/Closed, red Rejected) · trade · due date (overdue in red). === 48:552 Annotation — Checklists v1
Checklists v1 — what changed
1

The header matches Defects and Site diary. Active checklists are rows in one bordered card: sentence-case name ("Contract to kick off · Rev 2"), muted "28 of 58" and a thin 3px progress line, with a muted ›. The grey Active pills are gone. Completed and Archived sit collapsed at the bottom.
