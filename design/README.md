# Morada build pack

Start with `PROMPT.md`. It contains the message Jed pastes into Claude Code.

| File | What it is |
|---|---|
| `PROMPT.md` | First message for Claude Code, plus follow-up phrases |
| `BUILD-SPEC.md` | Principles + every approved screen (Figma link, PNG, layout, states, interactions, done-when) |
| `COMPONENTS.md` | Shared components to build first, with measurements and icon mapping |
| `BUILD-ORDER.md` | Phases and the stop-after-each-screen rule |
| `GOTCHAS.md` | Traps: tabular numbers, carets, broken product images, dummy data, old Figma variables… |
| `tokens/theme.ts` | Colours, Inter type scale, radii, spacing, shadows, breakpoint |
| `screens/` | 39 PNGs (2×): 32 phone frames for 18 phone screens + 7 Duo screens |
| `reference/figma-layout-dump.txt` | Exact frame tree with measurements for every approved frame |
| `reference/annotations.txt` | Designer notes from Figma |

Figma: https://www.figma.com/design/purB3wnrQmpAgjBmG4fQiP (page "Revamp")
